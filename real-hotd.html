PUBLIC PLAYABLE GATE: NOT PASSED

The runtime test worked. The deployed game did not.

The CI runner temporarily reconstructed the official-era HOTD demo from an archival PC Zone CD, zipped the extracted game as site/hotd.zip, and served that file only inside the temporary runner. The proof then launched Wine in Chromium and observed changing frames. After the test, hotd.zip was deleted and was never included in GitHub Pages.

WHAT PASSED

BoxedWine 26R1 / Wine 6 started the HOTD executables in a temporary Chromium test without the crash signatures we were tracking.

WHAT DID NOT PASS

There is no HOTD game body on the public Pages deployment, so opening this site alone cannot launch the 1997 game.

PROOF LIMITATION

Frame deltas are a runtime smoke signal, not proof that a human can enter gameplay, aim, shoot, and complete a level.
